This entry is a tiny Python program for the [make.fun](https://make.fun) one-line roast competition: it writes a single short roast about the everyday gadget we all depend on — a joke about a device that gives up long before the day does. Run `main.py` and it produces `entry.txt` containing exactly that one line.
